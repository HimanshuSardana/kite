Features
  • Blazing builds: pages compile in single-digit milliseconds — the whole site before your finger leaves Enter
  • Zero dependencies: one go install, no Node, no bundler, no lockfile
  • Plain-HTML themes: two template files in standard Go html/template — nothing new to learn
  • Live reload: kite serve watches content, themes and config and refreshes your browser — see the CLI
  • RSS included: feed.xml regenerates on every build, zero plugins
  • Table of contents: headings parsed into structured data — render a sidebar, a dropdown, or nothing
  • 10 built-in themes: from gruvbox to tufte — browse below
  • Open source: free, source on GitHub — why it exists

Benchmarks

No build daemon or cache to warm — the whole site is re-parsed and re-rendered on every build. Measured on an Intel i5-8250U (2017 laptop).

  • Parse one post: frontmatter and Markdown rendered to HTML in ~0.09 ms
  • Build 100 posts: the full site from scratch in ~45 ms
  • Build 500 posts: ~230 ms — about 0.5 ms per page
  • Build this docs site: ~6 ms, or ~12 ms cold including process start
  • Single static binary: ~12 MB stripped, no runtime or lockfile
FAQ

Is kite free?

Yes — free and open source. Grab it with go install (needs Go 1.25+). The output is plain static HTML, hostable anywhere.

Why another static site generator?

Hugo is powerful but brings its own templating world; JS frameworks burn 100MB of RAM to render Markdown. Kite is the smallest tool that does the job — full story here.

Can I bring my own theme?

Yes — home.html + layout.html in standard Go template syntax. This page is a custom theme — guide here.

Does it do RSS? Drafts? Taxonomies?

RSS yes, every build. Drafts yes — draft: true hides a post until you build with --drafts. Taxonomies: not yet — if you need those today, Hugo is the honest recommendation.
